SECURITY & RESPONSIBILITY

Access & roles.

A proposed permission model to prevent employee data and administrator controls from being mixed together.

Requires backend changes
Important: the extra roles below are a design proposal, not current permissions.

The repository documents only admin and employee roles. The backend must enforce every permission server-side before these role levels can be enabled in production. Hiding a button is not access control.

Proposed

Super Admin

Owns system configuration, admin access and organisation-wide security policy.

Current role · admin

Administrator

Manages employee accounts, branch records and attendance logs within the organisation.

Proposed

Branch Manager

Reviews activity and employee assignments only for explicitly assigned locations.

Current role · employee

Employee

Accesses their own pass and personal attendance history, never the full directory.
